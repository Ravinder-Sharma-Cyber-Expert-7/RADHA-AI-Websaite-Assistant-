# 🌸 RADHA AI — Emotionally Intelligent Personal Voice Assistant

**Radha AI** is a next-generation, full-stack, emotionally intelligent AI voice assistant built to bridge the gap between cold, robotic chatbots and genuine human-like companionship & automation.

Designed and architected by **Ravinder Sharma**, Radha combines real-time voice interaction, deep emotional sentiment awareness, proactive daily routine care, and live real-world utilities into a sleek, minimal, APK-ready interface.

🔗 **Live Interactive Demo:** [Launch Radha AI](https://ai.studio/apps/cebbe4a7-041d-4cec-ac75-b8a45589c729?fullscreenApplet=true)

---

## ✨ Key Features

- 🎙️ **Natural Voice & Wake-Word Engine (`liveService.ts`, `audioUtils.ts`):** Instant wake-word activation ("Radha") with natural conversational responses, real-time audio visualization, and smooth turn-taking.
- ❤️ **Deep Emotional Intelligence & Sentiment Analysis (`sentimentService.ts`, `BossSentimentPanel.tsx`):** Understands human moods, feelings, stress, and tone—responding with genuine empathy rather than robotic scripts.
- 🕰️ **Proactive Daily Routine & Health Care (`routineCareService.ts`, `fitnessService.ts`):** Time-aware companion that checks in on meals, hydration, morning routines, and well-being—powered by smart anti-repetition state memory.
- 🧠 **Persistent Long-Term Context Memory (`memoryService.ts`):** Remembers past conversations, preferences, and daily completed tasks so interactions feel continuous and human.
- 🌦️ **Real-Time Live Weather (`weatherService.ts`, `WeatherWidget.tsx`):** Fetches live location-based weather, temperature, and conditions on voice command.
- 🔋 **Live Device Telemetry & Smart Care (`deviceCareService.ts`):** Monitors real battery levels and network status, proactively alerting the user when battery runs low.
- ⚡ **Smart Command Hub & Workspace Drawer (`SmartCommandHub.tsx`, `CommandDrawer.tsx`, `SocialWorkspacePanel.tsx`):** Clean, clutter-free main display with a collapsible glassmorphic command drawer for notes, reminders, quick actions, and social/workspace insights.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js (`server.ts`)
- **AI Engine:** Google Gemini API & Google AI Studio
- **Audio & Real-Time UI:** Web Speech API, Custom Audio Visualizer, Neural Consciousness Field UI
